# World.Execute-me-

You'll need dotnet-8.0

A console visualisation of World.Execute(Me); .

This is for Windows

Make a new directory "mkdir [NAME]"

move to the directory "cd [NAME]"

run "dotnet new console"
and "dotnet add package NAudio --version 2.4.0"
Make sure you have dotnet installed, preferably 8.0.403.
run "dotnet run" via cmd.
then type "world.execute(me);"
The computer won't show up at first so just keep typing "world.execute(me);"
